# Links de WhatsApp dos serviços

- O link é gerado a partir de `siteConfig/public.whatsappUrl` (configurado em `/admin`) + a mensagem
  "Olá, gostaria de saber mais sobre os serviços do Herói da Cidade! Tenho interesse no [Título]".
- Campo `whatsappUrlSource` no serviço: `'auto'` (gerado, acompanha título e número), `'manual'`
  (link informado explicitamente, nunca é sobrescrito). **Ausente em documentos antigos** = tratado como não gerenciado.
- Ao salvar um novo número em `/admin`, `syncAutoServiceWhatsAppUrls()` atualiza apenas serviços `'auto'`.
- Documentos antigos só passam a `'auto'` quando o título é editado **e** o link atual parece gerado do título anterior.

## Migrar serviços antigos para `auto` (procedimento seguro, NÃO executado)

1. Backup: exportar a coleção `services` (`gcloud firestore export` ou export no console).
2. Dry-run: listar documentos sem `whatsappUrlSource` cujo `looksAutoGenerated(whatsappUrl, title)` (em `services/serviceWhatsApp.js`) é verdadeiro. Revisar a lista manualmente: o que for link personalizado fica de fora.
3. Testar o lote no emulador/ambiente de homologação.
4. Em produção, gravar `whatsappUrlSource: 'auto'` somente nos IDs aprovados (sem mexer em `whatsappUrl`); depois rodar `syncAutoServiceWhatsAppUrls({ dryRun: true })` e conferir antes de aplicar.
5. Rollback: restaurar o export ou remover o campo `whatsappUrlSource` (volta ao comportamento anterior).
